SECTION 1: INTRODUCTION TO COMPUTERS (Q1–Q10)
Q1. What is a computer?
Answer: A computer is an electronic device that accepts data as input, processes it according to instructions, stores it and produces meaningful information as output.
A computer performs four basic operations:
    1. Input.
    2. Processing.
    3. Storage.
    4. Output.
Example: A computer used on a ship can process navigation information, prepare reports, store documents and communicate information.
Q2. What are the main characteristics of a computer?
Answer: The main characteristics of a computer are:
    1. Speed: Performs millions or billions of operations per second.
    2. Accuracy: Produces accurate results when given correct data and instructions.
    3. Storage: Stores large amounts of information.
    4. Diligence: Performs repetitive tasks without getting tired.
    5. Automation: Performs tasks automatically once instructed.
    6. Versatility: Performs different types of tasks.
    7. Reliability: Produces consistent results under proper operating conditions.
Q3. What are the basic functions of a computer?
Answer: A computer performs five basic functions:
    • Input: Accepting data.
    • Processing: Performing calculations and operations.
    • Output: Displaying results.
    • Storage: Saving information.
    • Control: Coordinating all computer operations.
Q4. What are the different types of computers?
Answer: Computers can be classified according to their size, processing power and purpose.
Based on size and processing power:
    1. Supercomputer.
    2. Mainframe computer.
    3. Minicomputer.
    4. Microcomputer.
Based on data handling:
    1. Analog computer.
    2. Digital computer.
    3. Hybrid computer.
Q5. What is a supercomputer?
Answer: A supercomputer is an extremely powerful computer designed to perform complex calculations at very high speeds.
Applications include:
    • Weather forecasting.
    • Climate modelling.
    • Scientific research.
    • Space research.
    • Oceanographic simulations.
Q6. What is a microcomputer?
Answer: A microcomputer is a small computer that uses a microprocessor as its central processing unit.
Examples:
    • Desktop computer.
    • Laptop.
    • Tablet.
    • Personal computer.
Q7. What is the difference between data and information?
Answer:
Data: Raw facts and figures that have not been processed.
Information: Processed and organised data that has meaning.
Example:
    • Data: 10, 15, 20, 25.
    • Information: The average of these four numbers is 17.5.
Q8. What is an IPO cycle in computers?
Answer: IPO stands for:
    • I – Input.
    • P – Processing.
    • O – Output.
It describes the basic working principle of a computer.
Example:
    1. Input: Entering two numbers.
    2. Processing: Adding the numbers.
    3. Output: Displaying the sum.
Q9. Who is known as the Father of Computers?
Answer: Charles Babbage is known as the Father of Computers.
He designed the Difference Engine and Analytical Engine, which laid the foundation for modern computing.
Q10. What are the advantages and disadvantages of computers?
Answer:
Advantages:
    1. High speed.
    2. Accuracy.
    3. Large storage capacity.
    4. Automation.
    5. Easy communication.
    6. Increased productivity.
    7. Quick information processing.
Disadvantages:
    1. Security threats.
    2. Dependence on electricity.
    3. Privacy concerns.
    4. Hardware failures.
    5. Potential data loss.
    6. Health problems from excessive usage.

SECTION 2: COMPUTER HARDWARE AND COMPONENTS (Q11–Q20)
Q11. What is computer hardware?
Answer: Computer hardware refers to the physical components of a computer that can be seen and touched.
Examples:
    • Monitor.
    • Keyboard.
    • Mouse.
    • CPU.
    • Motherboard.
    • RAM.
    • Hard disk.
    • Printer.
Q12. What is computer software?
Answer: Software is a collection of programs and instructions that tells a computer what to do.
Examples:
    • Windows.
    • Linux.
    • Microsoft Word.
    • Microsoft Excel.
    • Google Chrome.
Q13. What is the difference between hardware and software?
Answer:
Hardware	Software
Physical components	Programs and instructions
Can be touched	Cannot be physically touched
Can wear out physically	Can become corrupted or outdated
Example: Keyboard	Example: MS Word
Requires software to perform useful tasks	Requires hardware to run
Q14. What is the CPU?
Answer: CPU stands for Central Processing Unit.
It is commonly called the brain of the computer because it executes instructions and processes data.
The main components of a CPU are:
    1. Arithmetic Logic Unit (ALU).
    2. Control Unit (CU).
    3. Registers.
Q15. What is the Arithmetic Logic Unit (ALU)?
Answer: ALU is a component of the CPU that performs arithmetic and logical operations.
Arithmetic operations:
    • Addition.
    • Subtraction.
    • Multiplication.
    • Division.
Logical operations:
    • AND.
    • OR.
    • NOT.
    • Comparisons.
Q16. What is the Control Unit (CU)?
Answer: The Control Unit manages and coordinates the operations of the computer.
Its functions include:
    1. Controlling instruction execution.
    2. Managing data flow.
    3. Coordinating CPU operations.
    4. Controlling input and output operations.
Q17. What is a motherboard?
Answer: A motherboard is the main printed circuit board of a computer.
It connects important components such as:
    • CPU.
    • RAM.
    • Storage devices.
    • Expansion cards.
    • Input/output connectors.
Q18. What is RAM?
Answer: RAM stands for Random Access Memory.
It is the primary memory used to temporarily store data and instructions that the CPU is currently using.
Characteristics:
    1. It is volatile memory.
    2. Data is normally lost when power is switched off.
    3. It provides fast access to working data.
    4. It supports multitasking.
Q19. What is ROM?
Answer: ROM stands for Read Only Memory.
It is non-volatile memory used to store firmware and other essential instructions.
Characteristics:
    1. Retains information without power.
    2. Stores firmware.
    3. Used during the computer startup process.
Q20. Differentiate between RAM and ROM.
Answer:
RAM	ROM
Random Access Memory	Read Only Memory
Usually volatile	Non-volatile
Temporarily stores working data	Stores firmware and essential instructions
Supports running applications	Supports system startup and hardware functions
Read and write operations	Traditionally mainly read operations

SECTION 4: COMPUTER MEMORY AND STORAGE DEVICES (Q31–Q40)
Q31. What is computer memory?
Answer: Computer memory is the storage area used to hold data, instructions and information required by a computer.
It is broadly classified into:
    1. Primary memory.
    2. Secondary memory.
Q32. What is primary memory?
Answer: Primary memory is the memory directly accessible by the CPU.
Examples:
    • RAM.
    • ROM.
    • Cache memory.
It is used to store data and instructions required during computer operations.
Q33. What is secondary memory?
Answer: Secondary memory is used for long-term storage of data and programs.
Examples:
    1. Hard Disk Drive (HDD).
    2. Solid State Drive (SSD).
    3. Pen drive.
    4. Memory card.
    5. CD.
    6. DVD.
Q34. What is cache memory?
Answer: Cache memory is a small, high-speed memory located in or near the CPU.
It stores frequently accessed data and instructions to improve processing speed.
Q35. What is a hard disk?
Answer: A Hard Disk Drive (HDD) is a secondary storage device that uses magnetic storage to store data.
It can store:
    • Operating systems.
    • Applications.
    • Documents.
    • Photographs.
    • Videos.
Q36. What is an SSD?
Answer: SSD stands for Solid State Drive.
It is a storage device that uses flash memory to store data.
Advantages:
    1. Faster data access.
    2. No moving mechanical parts.
    3. Lower noise.
    4. Better resistance to physical shock than conventional HDDs.
Q37. What is a pen drive?
Answer: A pen drive is a small portable storage device that uses flash memory and connects through a USB port.
It is used to transfer and store files.
Q38. What are the units of computer memory?
Answer:
Common units include:
Unit	Value
Bit	0 or 1
Nibble	4 bits
Byte	8 bits
Kilobyte (KB)	1,024 bytes
Megabyte (MB)	1,024 KB
Gigabyte (GB)	1,024 MB
Terabyte (TB)	1,024 GB
Note: These are the traditional binary-based conversions commonly used in introductory computer studies.
Q39. What is the difference between volatile and non-volatile memory?
Answer:
Volatile memory:
    • Requires power to retain data.
    • Data is normally lost when power is switched off.
    • Example: RAM.
Non-volatile memory:
    • Retains data without power.
    • Used for permanent or long-term storage.
    • Examples: ROM, SSD and HDD.
Q40. What is a backup?
Answer: A backup is an additional copy of important data stored separately so that the information can be recovered if the original data is lost, damaged or corrupted.
Examples:
    • External hard drive backup.
    • Cloud backup.
    • Separate secure storage.
Maritime application: Maintaining backups of important vessel records, reports and operational documents helps protect essential information.

SECTION 8: CYBERSECURITY AND COMPUTER SAFETY (Q71–Q80)
Q71. What is cybersecurity?
Answer: Cybersecurity is the practice of protecting computers, networks, systems and data from unauthorised access, attacks, damage and theft.
It is particularly important in the maritime industry because ships increasingly depend on digital systems.
Q72. What is a computer virus?
Answer: A computer virus is a type of malicious software that attaches itself to legitimate files or programs and can spread when infected content is executed.
It may damage files, disrupt operations or steal information.
Q73. What is malware?
Answer: Malware is short for malicious software.
It refers to software designed to harm, disrupt, spy on or gain unauthorised access to computer systems.
Types include:
    1. Viruses.
    2. Worms.
    3. Trojans.
    4. Ransomware.
    5. Spyware.
    6. Adware.
Q74. What is phishing?
Answer: Phishing is a cyberattack in which criminals use deceptive emails, messages or websites to trick people into revealing confidential information.
Examples of information targeted include:
    • Passwords.
    • Banking information.
    • Personal details.
    • Login credentials.
Q75. What is a firewall?
Answer: A firewall is a network security system that monitors and controls incoming and outgoing network traffic according to predetermined security rules.
It helps prevent unauthorised network access.
Q76. What is a password?
Answer: A password is a secret combination of characters used to authenticate a user's identity and protect access to a computer system or account.
A strong password should:
    1. Be sufficiently long.
    2. Be difficult to guess.
    3. Avoid personal information.
    4. Be unique for each important account.
Q77. What is two-factor authentication (2FA)?
Answer: Two-factor authentication is a security method that requires two different forms of verification before granting access to an account.
Example:
    1. Password.
    2. One-time verification code.
Q78. What is ransomware?
Answer: Ransomware is a type of malicious software that blocks access to files or systems, commonly by encrypting data, and demands payment for restoration.
It can seriously affect organisations that depend on digital records.
Q79. What is data privacy?
Answer: Data privacy refers to the proper handling, protection and use of personal and confidential information.
It ensures that information is accessed and used only by authorised individuals.
Q80. Why is cybersecurity important on ships?
Answer: Cybersecurity is important on ships because modern vessels use interconnected digital systems for navigation, communication, machinery monitoring and administrative operations.
Cyber incidents can affect:
    1. Navigation systems.
    2. Communication systems.
    3. Cargo management.
    4. Engine monitoring.
    5. Electronic records.
    6. Operational safety.
Crew members should follow company cybersecurity procedures and avoid connecting unauthorised devices to shipboard systems.

SECTION 9: COMPUTER APPLICATIONS IN THE MARITIME INDUSTRY (Q81–Q90)
This section is especially important for B.Sc. Nautical Science students because it connects Computer Science with your future profession as a Deck Officer.
Q81. How are computers used in the maritime industry?
Answer: Computers are used in modern ships for:
    1. Navigation.
    2. Communication.
    3. Weather monitoring.
    4. Cargo management.
    5. Engine monitoring.
    6. Ship administration.
    7. Safety management.
    8. Record keeping.
Q82. What is ECDIS?
Answer: ECDIS stands for Electronic Chart Display and Information System.
It is a navigation information system that displays selected electronic navigational charts and integrates relevant navigational information.
Its functions include:
    • Displaying electronic charts.
    • Showing the ship's position.
    • Displaying planned routes.
    • Supporting route monitoring.
    • Providing navigational alarms and indications.
ECDIS is an important system used by modern merchant ships.
Q83. What is GPS?
Answer: GPS stands for Global Positioning System.
It is a satellite-based navigation system developed by the United States.
It provides information such as:
    1. Position.
    2. Speed.
    3. Time.
    4. Direction of movement.
GPS is widely used in maritime navigation.
Q84. What is AIS?
Answer: AIS stands for Automatic Identification System.
It is a maritime communication and identification system that automatically exchanges information between suitably equipped vessels and relevant shore stations.
Information may include:
    • Ship identity.
    • Position.
    • Course.
    • Speed.
    • Navigation status.
AIS assists in situational awareness and collision avoidance but does not replace proper lookout or radar-based navigation.
Q85. What is Radar?
Answer: RADAR stands for Radio Detection and Ranging.
It is an electronic system that uses radio waves to detect objects and determine information such as their range and bearing.
Maritime radar helps in:
    1. Detecting nearby vessels.
    2. Detecting land.
    3. Monitoring navigational hazards.
    4. Supporting collision avoidance.
    5. Navigating in restricted visibility.
Q86. What is a VDR?
Answer: VDR stands for Voyage Data Recorder.
It is a system fitted to applicable ships that records selected information relating to the ship's operation and navigation.
It is sometimes described as the ship's black box.
Recorded information can help investigators understand the circumstances surrounding a maritime accident.
Q87. What is a BNWAS?
Answer: BNWAS stands for Bridge Navigational Watch Alarm System.
It monitors bridge activity and alerts the crew if the bridge watch officer becomes inactive for a specified period.
Its purpose is to help maintain an effective navigational watch.
Q88. What is a GMDSS?
Answer: GMDSS stands for Global Maritime Distress and Safety System.
It is an internationally recognised system for maritime distress alerting and safety communications.
It uses various communication technologies to support:
    1. Distress alerts.
    2. Search and rescue coordination.
    3. Maritime safety information.
    4. General maritime communications.
Q89. What is a shipboard computer network?
Answer: A shipboard computer network is a system connecting computers and digital devices onboard a vessel to exchange information and share resources.
It may support:
    • Administrative work.
    • Operational information.
    • Maintenance records.
    • Communication.
    • Approved navigation-related applications.
Q90. What is the importance of computers in modern navigation?
Answer: Computers are important in modern navigation because they help officers process, display and analyse navigational information.
They support:
    1. Position monitoring.
    2. Route planning.
    3. Electronic chart display.
    4. Radar information processing.
    5. AIS information display.
    6. Weather information access.
    7. Voyage documentation.
However, a navigating officer must understand the limitations of electronic equipment and maintain independent navigational checks.

My Advice for You as a Nautical Science Student
Do not study Computer Science only as a theory subject. Try to understand how computers are used in the actual Merchant Navy.
Pay particular attention to these five areas:
    1. MS Excel: Learn formulas, calculations, tables and charts. These skills are useful for maintaining records and preparing reports.
    2. MS Word: Learn to prepare professional documents, inspection reports and checklists.
    3. Computer Networking: Understand LAN, WAN, IP addresses, routers and basic network security.
